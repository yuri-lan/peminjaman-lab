# 📚 Aplikasi Peminjaman Barang Laboratorium

Aplikasi web untuk mengelola peminjaman barang di laboratorium sekolah. **Frontend-only** — data disimpan di LocalStorage browser. Bisa langsung di-hosting di GitHub Pages.

## 🛠️ Tech Stack
- **HTML5** + **CSS3** (Neumorphism)
- **JavaScript Vanilla**
- **LocalStorage** (database di browser)

## ✨ Fitur
- 🔐 Login Admin & Siswa
- 📦 CRUD Data Barang
- 👥 CRUD Data Siswa
- 📝 Transaksi Peminjaman
- 📥 Pengembalian + denda otomatis (Rp 2.000/hari)
- 📊 Laporan + Cetak
- 🎓 Area Siswa
